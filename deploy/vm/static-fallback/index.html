Ratchet is regression CI for self-improving agents: every skill edit is replayed against the agent's blessed past runs, judged by a Nemotron cascade, and blocked if it breaks something that used to work. While we bring the live host back, the walkthrough below shows the full loop.

__RATCHET_VIDEO_EMBED__
  • ReplayEach edit re-runs blessed tasks in a sandbox, with side effects served from cassettes.
  • JudgeLevel 0 diff, then Nano, Super and Ultra only where needed, with cost per tier.
  • DriftTavily checks whether the world changed before a divergence counts as a regression.
  • ActMerge, hold or revert on git, with the evidence on the verdict page.

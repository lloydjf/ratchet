Ratchet regression CI for self-improving agents

Your agent learns new skills every day. Ratchet makes sure it never unlearns the old ones.

$ uv tool install ratchet-ci
Demo → Docs GitHub
  1. 01 · replay

    Every skill edit re-runs the tasks you blessed, in a sandbox, against recorded tool calls.

  2. 02 · judge

    A Nemotron cascade, Nano → Super → Ultra, compares each run with the blessed one. A drift check tells a changed world from a broken skill.

  3. 03 · block

    Regressions block the edit, uncertain verdicts are held for review, and the rest merge.

Measured on SkillRegress-Bench: 35 labeled skill edits across six regression types and two controls, with recall, false blocks and cost per verdict for each judge setup. Read the results →

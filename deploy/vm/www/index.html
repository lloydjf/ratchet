Your agent learns new skills every day. Ratchet makes sure it never unlearns the old ones.

When the agent edits one of its skills, Ratchet replays the tasks you already blessed in a sandbox, judges every replay with a Nemotron cascade, and blocks the edit if anything got worse.

Open the demo Read the docs

Install the CLI

$ uv tool install ratchet-ci

One click selects the line. Python 3.11+; starts on the offline simulator, no keys needed. Source on GitHub

How it works

Replay

Every skill edit re-runs the tasks you blessed, plus three canaries, in fresh sandboxes on the same model tier, with side effects served from recorded cassettes.

t007 github.close_issue
  {"issue": 71, "reason": "not_planned"}
  → 409 ratchet_blocked

From the recording above: the sandbox refuses a write the blessed run never made, so nothing real is closed.

Judge

Level 0 diffs side effects with no model. Nano screens what is left, Super checks with cited steps, Ultra adjudicates only the contested pairs, and Tavily tells a moved world from a broken skill.

Block

A block needs a Level 0 hard fail, or Super and Ultra agreeing. A verdict that stays unsure is held for a person and never passed.

Passed
merged into main
Held
kept on candidate for review
Blocked
reverted on candidate; main never changes

Every action is a git commit with an undo path.
